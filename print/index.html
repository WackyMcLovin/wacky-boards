Want labels to print with no pop-up? Chrome normally asks "Print?" every time. To skip that, open Chrome with the print pop-up turned off:

Mac: quit Chrome, open the Terminal app, paste this and press Enter:
open -na "Google Chrome" --args --kiosk-printing https://boards.wackymclovin.com/print/

Windows: right-click your Chrome shortcut > Properties > at the end of Target add a space and --kiosk-printing > OK. Open Chrome from that shortcut.

Then set your label printer as the default printer (the first time, print one test label and pick it in the pop-up). Labels print to the default printer from then on.
