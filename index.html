Quick reference

The full step by step guide (with the gear list) is on the How to use page and in Downloads.

Switching to a new tab (the LIVE tab)

  1. For each new game, duplicate the AUCTION, $10 or $30 tab and give it a new name, like 9_16_26_AUC.
  2. Type that exact name next to the board in the LIVE tab (column B). The board on stream switches over within a few seconds. Column C can point at a different chase tab; leave it blank to keep the normal one.
  3. No LIVE tab, or a blank cell? The board just uses AUCTION / $10 / $30 like before. A misspelled name keeps the last good game on screen.

Running a night (same sheet as always)

  1. Type buyers into the AUCTION, $10 or $30 tab like normal: spot number in A, username in B, bid in C (type FREE for the free spot, winner in D to tag a winner).
  2. Set the chase in the matching _CHASE tab: picture link in B1, chase name in B2, prize in B3. The board plays a reveal when it changes.
  3. Optional extras in a _CHASE tab: add a row with Box in column A and the box name in B, or Chase 2 Image URL / Chase 2 Name / Chase 2 Value to show up to 4 chases.
  4. When a break is done: either point the LIVE tab at a fresh tab, or (the old way) duplicate the tab to save it with the date and clear the live one.

The extra games (RTYH, Pick Your Type, Case Break, Wall of Hits)

  1. Each one has its own Google Sheet (use the Open its Google Sheet link on its card). Only change the yellow boxes and the rows under the gold headers.
  2. RTYH: add a row at the bottom for each new ripper, bump PACKS as you open, and type the HIT CARD when it lands. The board plays a HIT! celebration.
  3. Pick Your Type: type the buyer next to their type or color. COLOR can be a name (red, fire, water...) or a code like #ff8800.
  4. Case Break: set each box to sealed, ripping or done, fill spots, and add hits at the bottom of the hit list.
  5. Wall of Hits: add each big pull at the bottom with a picture link. The newest one gets the spotlight.
  6. Add ?sound=1 to a board link for a short chime on each hit.

Rewards and real slab photos

  1. Rewards live in each board's _CHASE tab. Picture in B1, name in B2, prize in B3. Show up to 4 by adding rows Chase 2 Image URL, Chase 2 Name, Chase 2 Value (and 3, 4).
  2. For a real photo of your own slab or prize: upload it to Google Drive, set sharing to Anyone with the link, and paste the share link in the picture cell.
  3. For a PSA slab: take a clear photo of the slab (or copy the photo from the PSA cert page) and use the Picture Link Maker.
  4. Easiest way to get any picture link: open the Picture Link Maker, drag the product photo onto it, click Copy link, and paste it in the sheet with Cmd+Shift+V.

Putting a board on stream

  1. Click OBS link on a board above. That copies an address that hides every button and message.
  2. In OBS add a Browser Source, paste the link. Use 1920 x 1080 for a wide scene, or 1080 x 1920 for Whatnot / TikTok (the board switches to the tall layout on its own).
  3. Want to put an old break back up? Add ?tab= and the tab name to the address, like auction/?tab=9_13_26_AUC.
